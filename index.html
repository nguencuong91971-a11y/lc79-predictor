⚙ Cấu hình GitHub Gist (lưu vĩnh viễn, đồng bộ mọi máy)

1. Vào github.com/settings/tokens → tạo Fine-grained token, chỉ cấp quyền Gists: Read and write.
2. Dán token vào ô trên. Nếu chưa có Gist ID, để trống rồi bấm "Lưu & Kết nối" → hệ thống tự tạo Gist mới và hiển thị ID.
3. Lần sau mở trên máy khác, chỉ cần dán token + Gist ID → toàn bộ lịch sử được tải về.
